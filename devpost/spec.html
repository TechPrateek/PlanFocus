Tech Stack Breakdown

React + Vite
Fast, modern UI layer with sub-second hot reloading.
TypeScript 5
Strict type safety across scheduling, models, and timers.
Tailwind CSS
Obsidian dark theme, responsive layout, Linear-like polish.
Web Audio API
Native synthesized harmonic bell chimes; zero audio 404s.
LocalStorage
Refresh-proof client-side persistence; zero login friction.
Priority Engine
Deterministic difficulty & deadline balancing algorithm.
